# rimfrost-framework-regel-openapi

OpenAPI definitions shared across all regel types (manual and machine-based).
Contains endpoints that are identical regardless of the rule implementation.

## Artifacts

- Maven artifact: <https://github.com/Forsakringskassan/repository>

## Modules

- `rimfrost-framework-regel-openapi-spec` — OpenAPI YAML spec artifact
- `rimfrost-framework-regel-openapi-jaxrs-spec` — Generated JAX-RS server stubs
